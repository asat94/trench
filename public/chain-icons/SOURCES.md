# Official chain icon sources

- Solana: official logomark SVG from https://solana.com/branding
- BNB Chain: official BNB SVG from the `bnb-chain/bnb-chain.github.io` documentation repository
- Robinhood Chain: `Robinhood_Avatar.jpg` from the official Robinhood Chain Brand Assets V1 package at https://docs.robinhood.com/chain/brand-guidelines/
- Base: `Base_square_blue.svg` from the official Base brand asset package at https://brand.base.org/
- Ethereum: official purple diamond SVG from https://ethereum.org/assets

The files are stored locally and displayed without modifying their artwork.
